# RTZ-UI — Universal UI Library

مكتبة واجهات Lua مبنية على Roblox UI، مستوحاة من Fluent وWindows 11، وهدفها توفير عناصر واجهة قابلة لإعادة الاستخدام.

## المزايا الحالية

- نوافذ وتبويبات وأقسام.
- عناصر Toggle وSlider وDropdown وInput وKeybind وColorpicker وButton وParagraph.
- إشعارات وDialogs.
- ثيمات متعددة ودعم Acrylic.
- SaveManager وInterfaceManager ضمن Addons.

## التوافق

تعتمد المكتبة على Roblox/Luau APIs مثل `Instance` و`Enum` و`TweenService` و`UserInputService`، ولذلك لا يمكن ضمان عملها على **كل Executor** بمجرد وصفها بأنها Universal. قد تختلف البيئات في دعم واجهات المستخدم، وخصائص Roblox الحديثة، وواجهات الحماية الاختيارية.

لتحسين التوافق، نوصي باختبار العناصر التالية في كل بيئة مستهدفة:
- إنشاء `ScreenGui` وعرضه.
- الإدخال بالماوس ولوحة المفاتيح واللمس.
- `CanvasGroup` وخصائص الشفافية المستخدمة في الثيمات.
- الحركات والإشعارات وإغلاق المكتبة وتنظيف الاتصالات.
- سلوك Acrylic؛ عطّله إذا لم تكن المؤثرات مدعومة أو كانت تسبب مشاكل أداء.

**مهم:** لا يوجد ضمان بالتوافق مع كل Executor أو كل إصدار. أبلغ عن المشكلة مع اسم البيئة وإصدارها، ورسالة الخطأ، وخطوات إعادة الإنتاج، دون إرسال رموز دخول أو بيانات خاصة.
