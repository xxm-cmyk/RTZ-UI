**RTZ-UI — Universal UI Library**

مكتبة واجهات Lua مصممة لتسهيل تطوير السكربتات واختبار المابات واكتشاف الثغرات الأمنية.

⚠️ **تنبيه وأمانة الاستخدام:**
هذه المكتبة مخصصة للاستخدام المشروع واختبار المابات التي تملكها أو لديك إذن باختبارها. يُمنع استخدامها للإضرار بمابات الآخرين أو استغلال ثغراتها دون إذن.

باستخدامك للمكتبة، أنت مسؤول عن طريقة استخدامها، ونخلي مسؤوليتنا عن الاستخدامات المخالفة التي لا نشارك فيها أو نشجع عليها.

**طوّر بأمانة، واختبر بمسؤولية.**
